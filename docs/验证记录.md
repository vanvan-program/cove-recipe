## 验证边界与真机验收

Redmi K70 / Android 16 未连接，尚未验证该真机上的提醒声音、振动、锁屏、省电模式及厂商后台限制，也未测量其提醒延迟。当前使用默认字体完成模拟器 UI 验证，系统大字体与超长文本仍需真机检查。

建议真机安装后用一条真实流程验收：录入菜谱并选择封面 → 搜索 → 加入及修改购物清单 → 厨房模式与短计时 → 锁屏/切后台观察提醒 → 备份并恢复。普通模式和省电模式分别记录提醒延迟。无需先卸载旧版本。

Android 8–15 的实体设备兼容性未实测。API 26 是工程最低支持版本，不等于全部旧设备已验证。系统强行停止应用不保证计时提醒；设备重启中断旧计时；备份恢复取消旧计时。
