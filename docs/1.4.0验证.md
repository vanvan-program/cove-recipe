# Cove Recipe 1.4.0 验证记录

日期：2026-10-15。包名 `cn.myrecipe.app`，versionCode 5。数据库版本 3，备份格式版本 3。

## 本次实现

按用户提供的 `Cove Recipe 1.4.0.md` 完成三项需求：

- 购物项名称下方增加小字“来自：菜名”，多道菜共用同名食材时合并来源并去重，长名称自动换行。菜谱详情、首页多选和购物页“从菜谱添加”三个入口均保留完整来源；手动项目不显示来源。采购备注、已买状态和删除撤销继续保留。来源保存添加时的菜名，删除或重命名菜谱不影响清单；旧版购物项不推测来源，重新从菜谱添加后会补入来源。
- 菜谱卡片支持长按拖动，选中时轻微放大并抬起，到列表边缘自动滚动，松手写入 Room。重启后保持顺序；编辑已有菜谱不会改变位置。筛选列表只调整对应的可见菜谱位置，隐藏菜谱保留原位置；置顶与普通菜谱在各自分组内排序，提供无障碍上移/下移。多选时禁用拖动。新建菜谱排在所在组前面；最近使用仅显示用过的菜谱，并使用保存的顺序。
- 食材与备菜之间新增“调料备注”。编辑页沿用食材的名称、数量、单位、用量说明以及增删排序操作，新增后自动聚焦名称。详情与厨房使用同样的横排卡片显示，可连同食材选入购物清单。未填写时不显示空区域。
