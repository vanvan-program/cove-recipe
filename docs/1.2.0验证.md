## 完成内容

- 按确认的设计方向统一标题、搜索框、菜谱卡片、详情时间和食材区域、购物清单与厨房计时面板。无封面继续显示纯文字，有封面的置顶菜谱使用大图。

- 多选改为 22dp 圆圈对勾图标，保留 48dp 点击区域和“多选 / 取消多选”无障碍说明；批量加入清单仍按食材名称去重。
