# Cove Recipe 1.3.0 验证记录

日期：2026-10-14。包名 `cn.myrecipe.app`，versionCode 4。数据库仍为版本 2，备份格式仍为版本 2，兼容原有格式 1。

## 本次改动

根据用户提供的 `Cove Recipe 1.3.0.md` 实现全部 6 项要求。文档内标题写为 1.1.0，本次版本按用户请求采用 1.3.0。

- 到时通知增加“确认”；前台提醒服务以闹钟用途循环震动，600ms 震动、400ms 间隔，直到确认。点击通知只打开厨房，不自动消除提醒；厨房和全局计时条也提供确认。确认带计时 token，旧按钮不能清除新计时。
- 购物清单和编辑页新增食材均自动聚焦名称、弹出键盘；编辑页先滚动到新增食材。
- 食材标题移除“参考用量”；详情和厨房面板横向排列并自动换行，数量与用量说明完整保留。
- 时长改为三个原生滚轮，小时 / 分钟 / 秒分别滑动选择，支持无障碍调节。范围保留为 1 秒至 7 天；零时长禁用确定，168 小时时分钟和秒自动归零。
- 返回应用或恢复计时状态时复用相同 token 的运行通知，不重复发布、重建系统 Chronometer；暂停、继续及修改时间生成新 token 后正常更新。到时提醒继续依赖 elapsedRealtime 精确闹钟。
- 升级包名、签名及原有数据结构不变。

## 验证结果

- 离线构建成功；16 项 JVM 单元测试通过；Lint 无问题（0 错误、0 警告）。
- Android 16 / API 36 专用模拟器完整回归 `OK (30 tests)`，记录见 `设备测试结果.txt`。包括新增食材聚焦、时分秒及零时长 / 7 天边界、后台真实闹钟、确认操作、失效确认按钮保护；通知开始、暂停、继续、修改和取消均通过。返回应用的通知 postTime 保持相同，验证不会重复重建倒计时通知。
- 实际手势将分钟滚轮从 01 滑到 02，确认后显示 `参考计时 02:00`。购物清单名称框聚焦且键盘出现。结果见 `130-qa.json`。
- 启动 6 秒计时后使用 `am kill` 回收应用进程，确认进程已不存在；后台精确闹钟重新启动应用并显示带“确认”的到时通知。

- 崩溃缓冲区无记录；计时错误日志无错误。见 `130-crash.txt`、`130-timer-errors.txt`。
