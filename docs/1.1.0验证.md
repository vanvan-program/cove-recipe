# Cove Recipe 1.1.0 验证记录

验证日期：2026-10-14。交付包：`dist/CoveRecipe-1.1.0.apk`。

## 本次完成

- 名称 Cove Recipe，versionCode 2，versionName 1.1.0，原包名 `cn.myrecipe.app` 保留。
- 使用用户提供的图标，生成各密度资源并接入自适应桌面图标；主题图标采用单色锅形。
- 备菜说明位于编辑页食材与做法之间；详情和厨房的食材面板支持查看，修改会参与未保存提醒。
- 菜谱、购物清单、设置使用同一 HorizontalPager，支持手势与点击导航的滑动动画。
- 悬浮圆角矩形底栏无外围底板；内容可从后方滚动，列表末尾留有 196dp 操作空间。
- 新建菜谱、添加食材按钮位于各页面右下角；收藏在详情操作，列表星标只显示状态。
- 无封面时不显示图片占位区；搜索框圆角为 24dp。
- 编辑页分类选择器可以新建并自动选中；分类管理与编辑页复用保存弹窗，校验错误就地显示。
